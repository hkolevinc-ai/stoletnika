# Stoletnika → Temu: GitHub пакет 1.4

## Стартиране

1. Разархивирай ZIP файла. Качи съдържанието в основната папка на GitHub хранилището и замени старите файлове. Включи `.github/workflows/stoletnika-temu.yml` и папката `templates`.
2. Избери **Actions → Stoletnika - Temu → Run workflow**.
3. Остави `mode = full` и стартирай.
4. Изтегли **Artifacts → stoletnika-temu-results**. В него са `TEMU_STOLETNIKA.xlsx`, извлечените данни и отчетът `review.csv`.

Пакетът включва оригиналния Temu шаблон. Основният workflow стартира автоматично Chrome в GitHub, сканира сайта и попълва Excel. Не изисква API ключ, платена scraping услуга, браузърен експорт или връзка на ChatGPT с GitHub. Инсталацията на зависимостите е автоматична в GitHub.

Качи файловете от ZIP, а не самия ZIP файл. Ако останат други стари workflow файлове, стартирай точно **Stoletnika - Temu**, от файла `stoletnika-temu.yml`.

## Обхват

Сканират се само продуктовите списъци в:

- https://stoletnika.eu/vendor/bilka-chudodeyka
- https://stoletnika.eu/vendor/herbalkan
- https://stoletnika.eu/category/hranitelni-dobavki?vendors=natural-factors,webber-naturals

Обхождат се всички страници. Филтърът за Natural Factors и Webber Naturals се запазва при пагинацията. Отварят се само продуктите, намерени в тези списъци, а марката на всяка продуктова страница се проверява повторно. Вариантите са отделни редове и повторенията се премахват по продуктов и вариантен идентификатор.

## Данни в шаблона

Цената е текущата продажна цена в **EUR**. Редовна цена се добавя само при действително намаление. Използват се снимките на конкретния продукт. Запазват се оригиналните технически листове, падащи менюта, валидации и първите четири реда. Продуктите започват от ред 5.

Неизвестни размери, тегло, точна наличност, категория и юридически данни остават празни и се отбелязват в `review.csv`. Изборът на производител и категория използва стойностите от приложения шаблон. Прегледай отчета преди качване в Temu; част от продуктите може да изискват категория извън този шаблон.

## Браузър и достъп

Версия 1.4 използва Chrome чрез директна CDP връзка и една последователна сесия с общи cookies. На GitHub работи с виртуален екран. Не използва предишния HTTP профил или Playwright Chromium като основен транспорт. Има пауза между страниците и време за зареждане на реалния каталог.

Провереният HTTP клиент получава Cloudflare HTTP 403 / код 1010. Минават 23 автоматични проверки, включително модел на браузъра, извличане на цените и попълване на оригиналния Excel. Средата тук отказва стартиране на Chrome поради ограничение на системните sockets. Затова реално браузърно сканиране от GitHub runner още не е потвърдено. Този пакет не гарантира достъп, ако сайтът отказва и Chrome от конкретния runner.

При отказ браузърът запазва `blocked_page.html`, `blocked_page.png`, `blocked_url.txt` и `network_diagnostics.json` и спира след първата отказана страница. Ако отказът се случи след извличане на част от продуктите, наличните редове и грешки се запазват, а workflow е неуспешен. Не се представя частичният каталог като пълен.

`mode = test` проверява само трите начални списъка и по един продукт: шест страници, без Excel. Използвай го за кратка диагностика при отказ. Основният режим е `full`.

Браузърната реализация използва nodriver 0.50.5: https://github.com/ultrafunkamsterdam/nodriver . Runner е `ubuntu-24.04`, който съдържа Chrome и Xvfb: https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md .

## Изходни файлове

- `TEMU_STOLETNIKA.xlsx` — попълненият оригинален шаблон.
- `products.json`, `discovery.json` — извлечени продукти и линкове.
- `review.csv`, `review.json` — липси и предупреждения по редове.
- `summary.json`, `errors.json` — обобщение и грешки.
- `network_diagnostics.json` и `blocked_page.*` — при отказ на достъп.
- `access_test.json` — само при `mode = test`.
