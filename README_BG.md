# Stoletnika → Temu, версия 1.2

Новият метод разделя изтеглянето и попълването на Excel:

1. Твоят Chrome изтегля публичния каталог и запазва един компресиран файл.
2. GitHub попълва приложения Temu шаблон от този файл, без заявки към Stoletnika.

Това променя мястото на извличане. Смяна на HTTP клиент и Chromium в GitHub не помогнаха: сайтът връща HTTP 403 и Cloudflare проверка от тези среди. Не са нужни Python, разширение, прокси или платена услуга на твоя компютър.

## Стартиране

1. Разархивирай пакета и отвори **STOLETNIKA_START.html** в Chrome.
2. Покажи лентата с отметки с **Ctrl + Shift + B**. Издърпай бутона **Stoletnika → Temu** върху нея.
3. Отвори `https://stoletnika.eu/vendor/herbalkan`, изчакай страницата да се зареди и натисни запазената отметка.
4. В появилия се панел натисни **Старт / Продължи**. Остави таба отворен.
5. При завършване избери **Изтегли каталога**. Файлът се казва `stoletnika-browser-export.json.gz`.
6. Замени всички файлове на скрейпъра в GitHub с файловете от този пакет, включително `.github/workflows/stoletnika-temu.yml`.
7. Качи изтегления файл в папката `data` на GitHub с точно това име. Премахни `(1)` от името, ако Chrome го е добавил.
8. След commit стартирай **Actions → Stoletnika - Temu from Chrome → Run workflow**.
9. Изтегли **Artifacts → stoletnika-temu-results**. Провери `review.csv` преди качване в Temu.

Ако GitHub уеб качването пропусне `.github`, създай или замени `.github/workflows/stoletnika-temu.yml` чрез **Add file → Create new file** и копирай съдържанието от пакета.

За последващо обновяване натисни **Ново сканиране** в панела, изтегли нов каталог, замени файла в `data` и стартирай нов workflow. Цените и наличностите са от момента на извличане в Chrome. Повторното изпълнение на GitHub само обработва вече изтеглените данни.

## Прекъсване и продължаване

След всеки продукт напредъкът се записва в този Chrome. Ако затвориш таба, отвори сайта отново, натисни отметката и избери **Старт / Продължи**. Използвай същия Chrome профил. Изчистване на данните за сайта или работа в инкогнито може да премахне запазения напредък.

При отказ на достъп или липсващи продуктови данни сканирането спира. Панелът показва конкретния адрес. Не изпраща серия от повторни заявки и не решава автоматично проверки за човек. Продължи, когато сайтът е достъпен в този Chrome.

Каталогът може да се изтегли само когато всички открити продукти са обработени. Импортерът също отказва непълен файл. В него няма бисквитки, данни за вход или съдържание от потребителския профил.

## Обхват

- `https://stoletnika.eu/vendor/bilka-chudodeyka`
- `https://stoletnika.eu/vendor/herbalkan`
- `https://stoletnika.eu/category/hranitelni-dobavki?vendors=natural-factors,webber-naturals`

Обхождат се всички страници в тези три обхвата. Филтърът за Natural Factors и Webber Naturals се запазва при странициране. Препоръчани продукти и други категории не се включват. Марката на всяка продуктова страница се проверява повторно. Реалните варианти са отделни редове.

## Попълване на Temu

- **Base Price - EUR:** текущата продажна цена в EUR, включително промоция. Валутата се проверява; цената в лева не се използва.
- **List Price - EUR:** редовната цена само при действително намаление. Иначе се използва разрешеното `N/A`.
- **Количество:** публикуваният точен брой при проследяване на складовата наличност; 0 при неналичен вариант. Неизвестният брой остава празен.
- **Снимки:** само снимките на конкретния продукт, в отделни колони.
- **Тегло и размери:** от публикувани данни или твоя настройка в `config.json`; липсващите стойности се отбелязват в отчета.
- **Категория:** само стойност от 166-те категории на шаблона. Неясни категории и продукти извън тях остават за преглед.
- **Производител:** само точна стойност от падащото меню. Непотвърдени юридически фирми остават празни.
- **EU Responsible person:** празно до потвърждение на правилната фирма.
- **Държава:** само изрично посочена информация или твоя настройка; не се извежда от баркода.
- **Shipping Template:** `Magazin`. **Handling Time:** `1 Day`.
- **Комплекти:** запазват общата цена и броя опаковки; смесените комплекти се отбелязват за преглед.
- **Описание:** фактическа информация за състав, опаковка, прием и предупреждения. Пълното оригинално описание остава в `products.json`.

Оригиналните менюта, технически листове и настройки на шаблона се запазват. Данните започват от ред 5. Липсващи задължителни данни не се измислят.

## Резултати

- `TEMU_STOLETNIKA.xlsx` — попълненият оригинален шаблон.
- `review.csv` и `review.json` — липсващи полета и предупреждения по редове.
- `summary.json` — брой продукти, варианти, марки, грешки и дата на източника.
- `products.json` — извлечени данни с EUR цени и време на изтегляне на всеки продукт.
- `mapped_rows.json` — подготвените стойности за шаблона.
- `errors.json` — грешки при обработка. При такива GitHub маркира изпълнението като неуспешно и запазва отчета.

## Проверки и ограничения

Импортът на компресирани данни, отхвърлянето на непълен каталог, ограничението до трите категории, EUR цените и запазването на оригиналния шаблон се проверяват автоматично. Върху 13 запазени реални продуктови страници е проверено, че компактният формат запазва същите цени, наличности, описания и снимки. Импортът им е изпълнен без мрежови заявки. Кодът за Chrome и HTML инструкцията са включени в пакета. Пълно извличане през твоя Chrome предстои да се потвърди; достъпът от тази среда е спрян от Cloudflare.

За обработка на файл с инсталиран Python 3.11+:

```bash
python scrape_stoletnika.py --browser-export data/stoletnika-browser-export.json.gz
```

Тази команда използва стандартната Python библиотека. Допълнителни пакети не са нужни за импорта и попълването на Excel. Директно HTTP сканиране е отделен режим `--online`; новият GitHub workflow не го използва.
