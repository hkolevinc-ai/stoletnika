# Stoletnika → Temu

## Поправка във версия 1.1

При отказ на стандартните HTTP заявки се използва Chrome. Основният HTTP клиент изпраща Chrome TLS профил и нормални browser headers. Резервният браузър поддържа бисквитки и изпълнява JavaScript. Workflow инсталира нужните компоненти автоматично.

При повторен отказ точният HTTP статус и използваният метод се записват в `network_diagnostics.json`, който е включен в GitHub Artifact. Страница с грешка или междинна проверка не се приема за каталог.

За обновяване заменете всички файлове от този пакет, включително `.github/workflows/stoletnika-temu.yml`, `requirements.txt` и папката `stoletnika`. След commit отворете Actions и стартирайте **нов Run workflow**. `Re-run jobs` на старото изпълнение използва стария commit.

Скрейпърът попълва приложения Temu шаблон с продукти само от:

- https://stoletnika.eu/vendor/bilka-chudodeyka
- https://stoletnika.eu/vendor/herbalkan
- https://stoletnika.eu/category/hranitelni-dobavki?vendors=natural-factors,webber-naturals

Обхожда всички страници. Запазва филтъра за двете марки на всяка страница. Не сканира целия сайт или други категории. Всеки реален вариант е отделен ред. Повторен продукт се премахва по идентификатор.

## Стартиране в GitHub

1. Разархивирайте ZIP файла на компютъра.
2. Качете в основната директория на хранилището всички файлове от пакета, включително `requirements.txt`, `scrape_stoletnika.py`, `config.json` и папките `stoletnika`, `templates`, `tests` и `.github`. Не качвайте самия ZIP вместо файловете.
3. Проверете, че съществува `.github/workflows/stoletnika-temu.yml`. Ако качването през уеб интерфейса пропусне скритата папка, създайте този файл чрез **Add file → Create new file** и копирайте съдържанието му.
4. Отворете **Actions → Stoletnika - Temu catalog → Run workflow**.
5. Оставете `limit = 0`, за да сканирате всички продукти. За кратка проба въведете например `10`.
6. След края на изпълнението изтеглете **Artifacts → stoletnika-temu-results**.

Зависимостите и Chromium се инсталират автоматично от workflow. Не са нужни токени или GitHub Secrets. Workflow се стартира ръчно. Този пакет не е качен автоматично във ваше хранилище.

## Резултат

- `TEMU_STOLETNIKA.xlsx` — попълненият оригинален шаблон. Данните започват от ред 5.
- `review.csv` — редове, липсващи задължителни полета и предупреждения. Отваря се в Excel.
- `summary.json` — брой продукти, варианти, марки и грешки.
- `products.json` — пълните изходни данни, описания и снимки.
- `discovery.json` — всички открити продуктови линкове и брой страници.
- `errors.json` — грешки при изтегляне или обработка. Ако има такива, изпълнението е маркирано като неуспешно и резултатът е частичен.
- `network_diagnostics.json` — HTTP статуси и методи при проблеми с достъпа до сайта.
- `mapped_rows.json`, `review.json` — същите данни за повторно попълване и подробен преглед.

## Как се попълва

- **Base Price - EUR**: текущата продажна цена в EUR, включително промоция. Скрейпърът проверява валутата и не използва вторичната цена в лева.
- **List Price - EUR**: редовната цена само при действително по-ниска промоционална цена. Ако няма такава, използва позволеното `N/A` в полето `Not available for List price`.
- **Количество**: публикуваният точен брой от CloudCart, когато има проследяване на наличностите. При неналичност — 0. При неизвестен брой остава празно, освен ако не зададете резервна стойност.
- **Тегло**: теглото в грамове от варианта или структурираното описание на сайта.
- **Снимки**: снимките на конкретния продукт, в отделни колони. Не се включват снимки на препоръчани продукти, лога или банери.
- **Категория**: само идентификатор от 166-те категории в приложения шаблон. Избира се по името и декларирания състав. Неясните категории се отбелязват за преглед. Продукти като глухарче и козметични спрейове може да нямат съответстваща категория в този шаблон.
- **Производител/марка**: само точна стойност от падащите менюта. За Билка Чудодейка не е потвърдено коя юридическа фирма от менюто съответства на марката, затова се оставя празно.
- **EU Responsible person**: оставено празно до потвърждение на правилната фирма. Наличието на `Geo Nutrition LTD.` в менюто само по себе си не доказва, че фирмата отговаря за всяка марка.
- **Държава**: от изрично посочената в описанието държава при производителя или от ваша настройка. Не се извежда от баркода.
- **Размери на пакета**: остават празни при липса на данни. Можете да зададете общи стойности по подразбиране или индивидуални стойности по продукт.
- **Shipping Template**: `Magazin`, както в приложения файл. **Handling Time**: `1 Day`, настройва се.
- **Промо комплекти**: запазват общата цена и броя опаковки. Смесените комплекти се отбелязват за проверка.
- **Описание**: фактическа информация за състав, опаковка, прием и предупреждения. Пълният текст от сайта се запазва в `products.json`.

Шаблонът запазва всичките си листове, падащи менюта, скрити метаданни и валидиране. Скрейпърът не променя снимките. Не попълва измислени дати на производство, срокове на годност или документи за конкретна партида.

Преди качване в Temu прегледайте `review.csv`. Успешното изпълнение означава завършено сканиране и попълване. Липсващите задължителни данни и непотвърдените категории трябва да бъдат допълнени.

## Настройки

В `config.json` стойността `null` означава „остави празно, ако не е налично на сайта“.

При желание за общи резервни стойности може да зададете:

```json
"default_weight_g": 1000,
"default_dimensions_cm": [20, 20, 20],
"stock_if_unknown": 20
```

Теглото се използва само когато няма публикувано. Размерите се използват като обща настройка и се отбелязват като резервни стойности. Реалната наличност има предимство пред резервната.

За индивидуална корекция използвайте ID от `review.csv`, например:

```json
"overrides": {
  "5894": {
    "category_id": "17526",
    "cells": {"LG": 5, "LH": 5, "LI": 15, "LY": "Bulgaria"}
  }
}
```

Това е пример за синтаксиса, не измерване на продукта. Попълнете вашите действителни стойности.

За фирма, потвърдена от вас, задайте `manufacturer`, `eu_responsible_person` и/или `country_of_origin` в настройката за съответната марка. Използвайте точния текст от менюто в шаблона. Непозволена стойност се отчита в прегледа.

## Стартиране локално

В Windows разархивирайте целия пакет и стартирайте `run_windows.bat`. Изисква предварително инсталиран Python 3.11 или по-нов. Файлът създава отделна Python среда, инсталира зависимостите и изтегля Chromium.

Това е и резервният вариант, ако сайтът продължи да отказва достъп от GitHub, но се отваря от вашия компютър. Блокиране по IP/мрежа не може да бъде поправено само с промяна на HTTP клиента.

Ръчно:

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium
python scrape_stoletnika.py
```

Изисква Python 3.11 или по-нов. При проблем с изтеглянето автоматично опитва и `curl`.

Повторно попълване от запазените данни без ново сканиране:

```bash
python scrape_stoletnika.py --offline-json output/products.json --out rebuilt
```

## Проверка

На 05.10.2026 са проверени 22 страници с общо 742 уникални продукта: 48 Билка Чудодейка, 164 Хербалкан и 530 от филтрираната категория. Извличането е проверено върху 13 реални продукта от четирите марки, включително тинктури, капсули, желирани таблетки, комплект от две опаковки и действителна промоция с различни текуща и редовна цена. Девет автоматични проверки преминаха успешно, включително съхраняване на менюта и метаданни и запазване на водещите нули в баркодове. Пълното изтегляне на 742 продуктови страници се извършва при стартиране на workflow.

За версия 1.1.0 новият Chrome HTTP клиент обходи повторно всичките 22 страници и откри същите 742 продукта. Пробното извличане и обработка на 6 продукта завърши без грешки. Всички 13 автоматични проверки преминават, включително разпознаване на HTTP 403/429, отхвърляне на междинни страници с HTTP 200 и преминаване към резервния браузър. Самото изтегляне през Chromium и изпълнението от GitHub не са потвърдени в тази среда; нужни са нов Run workflow и проверка на неговия резултат.
